## 限制与接受范围

桌面锁只协调共享同一 canonical root 的调用者；崩溃或适配器异常可能保守留锁，需要外部确认后恢复。CleanupHandle 没有强制中止能力，超时只隔离。frozen dataclass 不深冻结 nested mapping，也不是 ACL。synthetic verifier 使用固定文件预期，只证明模拟文件事实；正式 GUI 必须另建可信工具观测与路径验证。
