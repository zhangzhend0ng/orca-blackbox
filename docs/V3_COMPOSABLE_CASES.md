# 可组合用例与多模型试点

同一条用例声明业务动作和验收关系，模型在开跑时绑定。新增模型通过输入文件进入，操作与验收通过登记的名称复用。

## 两份合同

| 合同 | 内容 |
|---|---|
| 用例模板 | 稳定 ID、目标角色、语义动作及参数、适用条件、必需判据。合法组合与依赖用例引用同一份配置依赖清单中的规则 ID。 |
| 已绑定运行计划 | 模板摘要、原始模型格式与文件摘要、导入策略、准备后的工程摘要、Orca 构建和预设、明确的目标实例、必需证据及 run ID。计划规范化后计算摘要，随产物回收。 |

模型来源负责准备输入。几何导入把模型放进明确的机器、材料和工艺上下文。完整工程重开保留内嵌配置、对象结构和覆写。Orca 校准向导是另一类来源，其输入包括阶梯范围、步长及材料等。三个来源产出相同的运行计划和对应的初态证据。

操作通过角色定位目标，用目标所在作用域解释坐标和参数。操作登记所需状态、参数和改动范围，可按前置条件排序或组合。UIA、菜单和视图定位由特定 Orca 构建对应的适配器负责。独立判据从受信输入和产物读取事实，检查差值、持久化或形状保持。需要几何触发条件的判据单独记录适用性。只有证据明确前提为假才标不适用，前提未知或目标歧义需保留阻塞原因。

合法组合与依赖试验共用配置规则。合法组合按规则过滤并覆盖取值对，再记录可行操作顺序。依赖试验独立使用触发、解除和恢复序列，允许输入预计会被 Orca 拒绝的配置，前提是已有可操作入口和可观察判据。

## 试点

首条模板对唯一可打印实例做全局 X+10 mm。输入边界为单实例毫米制 3MF 或 STL 网格。用统一的几何导入策略准备 U1 0.8 mm 工程，在床内留出平移空间。每次保存原始模型摘要、准备工程和计划。以相同操作适配器编辑并保存，停输后复用原有 runner 在不同 PID 和新 profile 中独立重开和导出。核对平移量、Y/Z、线性变换、局部网格、工艺设置和移动后物体的实际 XY 挤出。来源为 3MF 时准备步骤按几何导入策略应用组件变换并建立独立工程，原文件保留用于溯源。

试点计划用既有 27 mm 立方体、Orca 自带 3DBenchy、仓库 Prusa STL，再临时指定一个模型文件。所有输入调用同一入口和同一模板。多实例选择、多板、多材料覆写和完整 3MF 保真是后续适配范围。温度塔等校准向导后续接线时，分别验收启动会话的校准 G-code、3MF 持久化以及在新会话用相同输入重新生成的行为。

运行记录需统计输入、阻塞原因、执行及通过数量、初态与产物摘要、独立重切和清理状态。历史立方体用例保留其原始验收证据。试点按 SHADOW 或 NON_GREEN 登记。

## 执行入口

```powershell
python -B tools/native_save_demo.py --actor script --model fixtures/Prusa.stl
```

`--model` 接收 STL 或 3MF 的本地路径。同一命令通过客机专用检出运行 `bound_model_move`，使用已验证的 U1 0.8 mm 预设上下文。宿主 `artifacts/native_save_demo/<run-id>/` 留存原始输入、准备工程及已绑定计划。客机执行前校验传输摘要，验收后由 `hv_harvest.ps1` 回收计划、输入工程、UI 记录、保存件及新进程导出的 G-code。宿主再核对回收计划和提交计划一致。

当前准备器以原有 3MF 作为 U1 配置和项目结构载体，完全替换其中的网格。输入会居中并落床。预检接受毫米制单实例 3MF 与 STL 网格，对格式、网格规模和移动后的床内范围做校验。试点的独立重切判据使用这一固定工艺的高度和对象标记语义。
