`machine_max_speed_x` 在基线和两份新导出里均为正常模式 500、备用模式 200 mm/s，外墙没有触及正常模式阈值。新导出使用 Klipper 方言，含加速度设置，未发现 `M203` 或 `SET_VELOCITY_LIMIT` 的 `VELOCITY=`。发布标签 `sm-v2.4.0` 中，`GCode.cpp` 3539–3551 行的机器包络写出仅覆盖 Marlin/RRF。该标签的 `GCode/GCodeProcessor.cpp` 2808–2822、3246–3259 行展示了预估处理按各轴分量限制内部速度。

可另建两份同一 U1、T0、0.42×0.20 mm 的长直墙项目，保留一条沿 X 的连续长段和一条同条件沿 Y 的连续长段。诊断项目两边统一用高于 500 的请求进给（例如 700 mm/s）、45 mm³/s 流量上限（预计允许约 609 mm/s）、较高且相同的 Y 上限，关闭层时间降速，并固定其他轴与加速度设置。两份工程只改正常模式 X 上限 650→500 mm/s。先在 650 对照件确认目标 X 段的预估速度确实超过 500，且没有其它瓶颈。匹配路径起终点、Z、方式和 E 后记录两份导出的 F、X 投影、机器指令以及逐段预估速度。若同一路径的 F 保持一致且只有 X 向预估速度随设置降到 500，则这项对照支持预估限速介入。固件实际限速需要另用相同路径和仅改变 X 限速的受控固件进行轨迹测量。当前只完成离线复算，上述对照尚未执行。
