# 复合业务的生成脚本与回放对照

从现有脚本选跨页工艺参数（`m5e_combo_params`）及比例与渐变混色（`m4i_mixing_slice`）。手写脚本复用现有驱动，ZCode 只拿业务终态与工具约束。两条均要求同一个保存工程独立重开和 GUI 切片；操作段以及启动至结果回收分别计时；本轮均为 SHADOW 或 NON_GREEN。

- 跨页工艺使用已绑定的 27 mm 立方体。目标为层高 0.30、填充 30%、开启 Normal (auto) 支撑，首层 0.40、Grid、几何和耗材保持。独立检查 3MF、重切配置块与 90 层实际立方体挤出。立方体场景检查支撑设置生效于切片配置，未判支撑线实际挤出。
- 混色用 `fixtures/mixed_filament_test.3mf`。已有比例方案保留，再添加同一 F3/F2 组合的 50/50 比例和 80→20 渐变，保留原对象分配与涂色。保存与独立重切须同时回显两条新稳定 ID 与相应模式；新方案是否被分配并挤出不作为本次持久化判据。历史开发产物虽有 5 种换刀标记，定义只有旧比例和新增渐变，当前判据拒绝 `mix_definition_persistence`。
