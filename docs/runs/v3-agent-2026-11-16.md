## 试点期间发现

1. PSDirect 返回字符串携带 Remoting 属性，直接 ConvertTo-Json 会成为对象：修为 detached child 对纯文本 UTF-8/base64 后落宿主文件；真实读回与图片 hash 均已验证。
2. hv_go 写死 `origin/main..HEAD`，当前仓库只有 software_testing 时在严格错误模式下阻断：改用当前分支 upstream；首次失败日志保留，未启动 GUI 后才重试。
3. PATH CLI 为 0.138.0，存在模型缓存 schema 不兼容；App 已装 native 为 0.169.0-alpha.11.1。新 native 无代理环境变量时等待 118.05 秒、5 次 WebSocket 超时后 HTTP fallback 才返回 READY；40 秒终止不能证明模型不响应。仅对子进程继承既有系统 HTTP/HTTPS 代理后，7.34 秒返回、无重试。未改系统配置或全局环境，未复制 OAuth 到客机或转用其他 API。最小文本探测只是通道证据，完整图片与动作结果见下。
