# 已验收操作的两两组合回放

首批使用 `fixtures/agent_layer_cube.3mf`、Quality 初态及固定客机布局。把已验收录制按业务动作拆为四个子项。混色的 Add Mix 使用另一份 fixture，保留原回放入口。

| 子项 | 前置条件 | 独立终态判据 |
|---|---|---|
| `move` 全局 X+10 mm | 原始位置的单立方体 | 保存 3MF 的全局 X 变换精确 +10 mm，Y/Z、形状、尺寸、旋转和材料保持。重切对象的实际挤出落在移动后的 XY 边界内。 |
| `layer` 层高 0.24 mm | Quality 基础模式，层高 0.40 mm | 3MF 和重切 G-code 都读出 0.24 mm，首层保持 0.40 mm，存在 112 层实际对象挤出。 |
| `seam` 接缝 Random | Quality 基础模式，Aligned 可读 | 选择后读回 Random。3MF 和重切 G-code 都读出 `seam_position=random`。 |
| `ironing` Topmost 熨烫 | Quality 基础模式，熨烫初始关闭 | 开启 Advanced，导航至 Ironing 并选择后读回 Topmost。3MF 和重切 G-code 都读出 `ironing_type=topmost`。 |

生成器应用各子项的状态变化筛选合法顺序，从每对取一个排列，并为平移与层高保留两个排列。批次计划列出 6 对、7 条序列，记录每个子项的来源 run、录制摘要、步骤边界、前置条件和终态要求。每条串接一个 UIA Save As，完成后停止输入、退出编辑进程、冻结保存产物，以新进程和新 profile 独立重开与重切。验收同时检查两个子项和其余 fixture 设置，回放不调用模型。

```powershell
python -B tools/native_pairwise_batch.py --plan-only
python -B tools/native_pairwise_batch.py
```

首条命令生成只读计划。第二条通过仓库宿主协调器和 `hv_go.ps1` 串行执行，逐条通过 `hv_harvest.ps1` 回收。可以重复传入 `--case` 选择登记用例。每批在 `artifacts/native_pairwise/<batch-id>/` 保存 `plan.json`、逐条结果 `results.ndjson` 和 `summary.json`。计划绑定脚本摘要及各自 run ID，证据位于 `artifacts/windows_mcp_harvest/<run-id>/`。

子项的步骤边界与来源录制摘要一起绑定。在已有录制发生变化时，生成器会报告摘要变化。重新核对步骤边界后，可将新的录制来源绑定到对应子项。
