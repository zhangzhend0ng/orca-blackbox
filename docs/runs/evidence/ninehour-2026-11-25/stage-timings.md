**口径**

- 阶段秒数是 `native_worker.log` 的阶段行（`[flow276]` / `[flow264] <阶段> ok=<0|1> seconds=<秒>`），经收据 `stages.list` 读出。

  `field.<字段>` 是包住 `locate.<字段>` 和 `edit_readback.<字段>` 的父段，单独列在每张表后面，只作对照，**不和子段相加，也不进叶段合计**。
- 差 = 候选 run 减去参照 run 的均值；参照是同机、同场景（同初态、同夹具）、同构建线上的 run。负数表示更快。K2 与 K1 比。
- 机内进程秒 = `process.json` 起止之差；宿主整轮秒 = `summary.json` 的 `host_wall_seconds`（含收割，只有客机写）；
  宿主编排秒 = 台账 `process_seconds`（客机是 `native_save_demo.py` 进程的墙钟，fa706g3 是从投递作业到收割拉取完成，含 10 秒一次的轮询，两台机器含义不同，不能互比）；
  动作秒 = `native_worker.json` 的 `script_action_elapsed_ns`；段外秒 = 动作秒 − 叶段合计，是动作阶段里没有阶段行的部分。

- #276 的链是 基线 → 就绪等待（eae2376）；#264 的链是 基线 → K1 就绪等待（3ef1f94）→ K2 滚轮一次到位（e3bfdfe；客机在合并提交 d5fc2fa 上跑，引擎相同）。
