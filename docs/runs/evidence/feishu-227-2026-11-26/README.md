2.4.0 上驾驶这条用例的三处事实：另存工程之后，在对象上发消息点击不会再选中它，所以每次动作前都走盘面右键菜单的 `Select All`；PageUp 按下即把选中对象绕 Z 轴转 45°，`R` 不是旋转快捷键，工具栏没有 Rotate 工具，gizmo 也没有数值框。

离线复核用 `tools/replay_case_evidence.py`：先核对清单里的字节数与 SHA-256，再只从归档文件重判，并做 23 个反例；每个收据启动一个独立进程，各约 6.3 秒。截图只核对是有效的画面，不用来判定动作——GREEN 轮上两次 Select All 前后的画面变化是 0.0，选中的证据是另存工程里的位移和面板读到的词。反例包括换成别的工程、空盘、30 mm 立方体、两个对象、对象在盘外、导入件不在床上、平移方向反过来、沿 Y 平移、平移出床、左转、绕 X 转、模板当导入件、另一轮的文件、源文件不是立方体、空白截图、编出来的筛选、文件框里输入了别的文件、清单不符、把 analysis 改成 PASS、选中记录指向别的对象、侧栏没有对象、记录的包围盒被改、按了别的键。
